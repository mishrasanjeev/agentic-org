54  # cross-loop guard trips tolerated in a test run.

# Trips, not distinct violations: one cross-loop use trips the guard about
# twice, so 54 trips is roughly 27 uses. Measured against this engine by
# counting trips per call site - 1 violation -> 1 trip, 2 -> 4, 3 -> 5,
# 5 -> 9, 10 -> 20, 20 -> 40 - the session wrapper trips on every violation
# while the connect and checkout hooks alternate, catching about half each
# (a warm connection is caught at checkout and invalidated, so the next
# violation finds an empty pool and is caught at connect). The first
# violation against a cold pool trips once. What matters for a ratchet is
# that the number is monotonic and reproducible.
#
# Measured by the CI integration job (pytest tests/integration tests/regression)
# on 2026-09-22; the unit job reports 0. See FINDINGS A-58. This number only
# moves down, which scripts/check_cross_loop_baseline.py enforces against main.
# A maintainer can still override deliberately: AGENTICORG_CROSS_LOOP_BASELINE
# replaces this number for one run, and AGENTICORG_DB_CROSS_LOOP_GUARD=off
# stops the counting altogether (the run then says so on its summary line).
