54  # cross-loop guard trips tolerated in a test run.
#
# Trips, not distinct violations: one cross-loop use usually trips the guard
# twice — the session wrapper sees it, then the poisoned connection is
# invalidated and the pool opens a replacement on the foreign loop, which the
# connect hook sees. (The first violation against a pool trips once, dying
# before a replacement is opened: measured 1 use -> 1 trip, 5 -> 11, 20 -> 40.)
# So 54 trips is roughly 27 distinct uses. What matters for a ratchet is that
# the number is monotonic and reproducible.
#
# Measured by the CI integration job (pytest tests/integration tests/regression)
# on 2026-09-22; the unit job reports 0. See FINDINGS A-58. This number only
# moves down, which scripts/check_cross_loop_baseline.py enforces against main.
# A maintainer can still override deliberately: AGENTICORG_CROSS_LOOP_BASELINE
# replaces this number for one run, and AGENTICORG_DB_CROSS_LOOP_GUARD=off
# stops the counting altogether (the run then says so on its summary line).
