# OACP Runtime Truth Inventory

Canonical end-to-end flow: [OACP end-user flow](end-user-flow.md). Launch closure source of truth: [OACP Runtime Launch Closure PRD](runtime-launch-closure-prd.md).

Status on 2026-10-20. This inventory describes the source on `main`, based on `api/v1/commerce_runtime.py`, `api/v1/commerce_ledger.py`, `api/v1/ucp_discovery.py`, `api/v1/commerce_ucp_publishing.py`, `api/v1/commerce_ucp.py`, `api/v1/commerce_acp.py`, `core/commerce/`, the AgenticOrg Commerce Runtime UI, and the OACP, ledger, UCP and ACP tests. The AgenticOrg production deployment does not include the artifact verification, arbiter, ledger, UCP or ACP work yet: confirm the deployed commit before treating any row below as live there. Grantex production issues ES256-signed OACP artifacts under its first OACP issuer key and serves its public Token Status List.

| Public channel launch | AgenticOrg + channel owners | Configure secrets, review channel policy, run webhook smoke, and verify source/freshness labels. |
| Multi-source conflict resolution | AgenticOrg + merchants | Define precedence when Shopify, OMS, ERP, WMS, and provider facts disagree. |
| Public self-service rollout | AgenticOrg | Self-service config UI/API is implemented; complete support runbooks, approval queue, and merchant-launch ops before broad public rollout. |
