## Understand separate cost sources

Hosted platform plans and external provider usage are different. Models, embeddings, calls, messaging, merchant systems and payment providers can charge independently. Self-hosting adds your infrastructure and operating costs. Do not assume an economy label means the provider is free for your account.

The hosted pricing page is generated from the platform's plan catalog. Use [Pricing](https://agenticorg.ai/pricing) and **Billing** in your workspace for current plan information rather than relying on a hard-coded price in a guide.

## Review a plan

Compare agent/run/storage allowances, required connector access, identity features, support and deployment needs. Ask the account owner to verify subscription status and currency. A plan upgrade does not configure provider keys or activate every optional feature.

Before a pilot, set a provider budget, expected workload, limits and an alert owner. Start with short tasks and read-only tools. For voice, approve destinations and calling windows; for RPA, avoid unnecessarily frequent schedules.

## Billing-console procedure

1. Open **Billing** with the account-owner/admin role.
2. Inspect the current plan and supported subscription/usage controls.
3. Review the requested change and terms before checkout.
4. Return from the billing-provider flow and confirm the recorded status.
5. If status is unclear, check the provider reference and contact support; do not repeatedly submit payment.

Platform subscription billing is separate from OACP buyer payment and merchant mandate execution.

## Send an actionable support request

Include the affected screen/flow, safe run/case reference, timestamp and timezone, selected company context, deployed version where available, expected versus actual behavior, and steps to reproduce. State whether the issue is hosted or self-managed and whether it blocks an external action.

Do not include passwords, raw API keys, full account numbers, identity documents or unredacted provider payloads. If evidence is sensitive, arrange the approved private support channel first.
